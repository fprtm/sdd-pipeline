# Definition of Done — Full-Team SDLC vNext

- [x] WP-00 audit is reproducible; ALN-001..015 have recorded dispositions.
- [x] WP-01 protocol digest, segments, metrics, sample floors, grading, privacy,
      and cost rules are frozen before candidate results.
- [ ] REQ-013..026 and REQ-NF-006..011 have passing mapped tests and evidence.
- [x] SEC-011..022 negative tests prove fail-closed trust boundaries.
- [x] A weak idea is rejected, another revised, and neither is forced to BUILD.
- [x] A2/A3 cannot self-approve; repository actor aliases never become human authority.
- [x] Release, rollback, observation, incident regression, and outcome review work
      on exact subjects without raw sensitive retention.
- [x] Both reference packs validate and cannot weaken global policy.
- [x] Legacy/report-only, explicit opt-in, missing capability, install/update,
      downgrade, and provider-neutral handoff paths pass.
- [ ] Six frozen benchmark segments meet per-segment protocol criteria in
      calibration and unseen cohorts; missingness and costs are reported.
- [ ] No P0/P1, unexplained P2/review/productivity regression, or aggregate masking.
- [x] Public command count remains eight and low-risk workflows remain usable.
- [x] Documentation maps claims to policy/mechanical/runtime/host-dependent truth
      without a duplicate normative SSOT.
- [x] Gate-effectiveness evidence identifies at least one keep/remove decision.
- [x] Independent verification is recorded or exact degraded human-review items remain.
- [ ] Human promotion authority explicitly chooses promote, revise, or reject;
      tests and version bumps never auto-promote.
