# Gold Foil / Premium

**When to use**: Luxury invitations, VIP membership products, or premium packaging-style digital experiences.
**Palette example**: #0D0D0D (deep black bg), #D4AF37 (metallic gold), #FFFFFF (crisp white text)
**Typography**: Trajan Pro (headings) / Cormorant Garamond (body)
**Visual traits**:
- Metallic gold gradient text/borders (linear-gradient #BF953F→#FCF6BA→#B38728 simulating foil shine)
- Black or deep-jewel-tone backgrounds to maximize gold contrast
- Fine hairline borders, embossed/engraved-looking icon treatments, ample negative space
**Not this if**: The brand is budget-friendly, playful, or tech-startup — gold foil signals exclusivity/expense, can feel gaudy if overused.

For deeper technique detail (exact CSS/animation implementation), web-search for "gold foil premium CSS design" rather than guessing — this file gives direction, not a full spec.
