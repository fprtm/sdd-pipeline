# Paper Texture / Craft

**When to use**: Editorial sites, stationery/print-adjacent brands, artisanal or handmade product shops wanting a warm, tactile, crafted feel.
**Palette example**: #F0E9DA (kraft paper bg), #C4A77D (cardboard tan), #8B3A2F (rust ink), #2F2A24 (dark brown text)
**Typography**: Freight Text (headings) / Tiempos Text (body)
**Visual traits**:
- Subtle paper-fiber/noise texture overlay (grain PNG or CSS noise filter at low opacity)
- Cut-paper/collage layering: torn edges, layered card shadows, washi-tape or staple accents
- Letterpress-style deboss effect on headings (subtle inset text-shadow)
**Not this if**: A crisp, digital-native, high-tech brand identity is needed.

For deeper technique detail (exact CSS/animation implementation), web-search for "paper texture craft CSS design" rather than guessing — this file gives direction, not a full spec.
