# Mid-Century Modern

**When to use**: Furniture, home goods, and lifestyle brands wanting a warm, optimistic 1950s-60s design-forward feel.
**Palette example**: #D9A05B (mustard), #7A9E7E (sage green), #C6543A (burnt orange), #FDF6E9 (warm cream bg)
**Typography**: Futura / Century Gothic (headings), Avenir (body)
**Visual traits**:
- Organic abstract shapes (boomerangs, amoebas) alongside clean geometric grids
- Muted, earthy-but-warm color combinations rather than saturated primaries
- Flat illustration with simple line work, tapered "hairpin leg" motifs
**Not this if**: The brand needs a cutting-edge tech or hyper-modern digital feel.

For deeper technique detail (exact CSS/animation implementation), web-search for "mid-century modern design CSS palette" rather than guessing — this file gives direction, not a full spec.
