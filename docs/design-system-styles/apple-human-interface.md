# Apple Human Interface Style

**When to use**: iOS/macOS-native apps and premium consumer products wanting restrained elegance and content-first clarity.
**Palette example**: #007AFF (iOS system blue), #F2F2F7 (light gray bg), #1C1C1E (near-black text/dark bg)
**Typography**: SF Pro Display (headings), SF Pro Text (body)
**Visual traits**:
- Frosted-glass translucency (vibrancy/blur) on nav bars and sheets
- Large, bold titles that shrink on scroll; generous rounded corners (continuous curvature)
- Content-first layouts with minimal chrome; system accent colors for interactive elements only
**Not this if**: Building for Android/Windows or a brand that wants heavy visual branding over platform-native restraint.

For deeper technique detail (exact CSS/animation implementation), web-search for "Apple Human Interface Guidelines CSS design" rather than guessing — this file gives direction, not a full spec.
