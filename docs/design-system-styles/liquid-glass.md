# Liquid Glass (Apple)

**When to use**: Premium consumer apps and OS-level interfaces wanting Apple's refined, dynamic, translucent-material feel (visionOS/iOS 18+ style).
**Palette example**: #FFFFFF at 40-60% opacity (glass surface), #007AFF (system blue accent), #1C1C1E (dark bg base), dynamic content-tinted refraction
**Typography**: SF Pro Display (headings) / SF Pro Text (body)
**Visual traits**:
- Real-time specular refraction/distortion of background content through glass shapes, not just blur
- Continuous "squircle" corner radii and fluid morphing transitions between states
- Light bends and bounces dynamically as elements move (dynamic reflections, not static shadows)
**Not this if**: Building outside Apple's ecosystem where no engineer wants to fight for GPU-heavy real-time refraction, or content-dense UI where translucency reduces legibility.

For deeper technique detail (exact CSS/animation implementation), web-search for "liquid glass Apple design CSS" rather than guessing — this file gives direction, not a full spec.
