# Constructivism (Soviet Poster)

**When to use**: Political/activist campaigns, avant-garde cultural events, and bold editorial brands wanting propaganda-poster urgency.
**Palette example**: #D62828 (revolutionary red), #1A1A1A (black), #F4F1DE (aged paper bg), #C9C9C9 (steel gray)
**Typography**: Rodchenko / Druk (bold condensed headings), Futura (body)
**Visual traits**:
- Diagonal compositions with dynamic angled type and photomontage elements
- Bold red/black/white palette with occasional single accent, heavy geometric shapes
- Large condensed sans headlines set at aggressive angles, industrial iconography (gears, factories, fists)
**Not this if**: The brand needs to feel gentle, neutral, or apolitical.

For deeper technique detail (exact CSS/animation implementation), web-search for "Constructivism Soviet propaganda poster design CSS" rather than guessing — this file gives direction, not a full spec.
