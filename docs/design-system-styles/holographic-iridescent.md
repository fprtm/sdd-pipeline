# Holographic / Iridescent

**When to use**: Beauty/fashion tech, music/festival brands, Gen-Z consumer products wanting a shiny, dreamy, futuristic pop feel.
**Palette example**: #C9A0FF (lavender), #94FFF4 (aqua shimmer), #FFB3E6 (pink shimmer), gradient sweep across all three
**Typography**: Clash Display (headings) / Satoshi (body)
**Visual traits**:
- Multi-stop pastel gradients shifting hue on scroll/hover (conic or linear rainbow sweeps)
- Foil/pearlescent sheen via overlaid diagonal white-to-transparent gloss streaks
- Chrome or glass-like specular highlights on buttons and cards
**Not this if**: Brand needs to feel serious, technical, or budget-conscious — holographic reads as expensive/playful, not utilitarian.

For deeper technique detail (exact CSS/animation implementation), web-search for "holographic iridescent CSS gradient design" rather than guessing — this file gives direction, not a full spec.
