# Watercolor

**When to use**: Artisanal brands, event/wedding sites, children's books or apps wanting a soft, painterly, emotionally warm feel.
**Palette example**: #D9C4E8 (lilac wash), #F4C2C2 (blush pink wash), #A8D5BA (mint wash), #FFFDF9 (paper white bg)
**Typography**: Playfair Display (headings) / Lora (body)
**Visual traits**:
- Soft bleeding-edge color washes (radial gradients with feathered, irregular alpha edges) as backgrounds/accents
- Visible paper-grain texture beneath translucent overlapping color layers
- Muted, low-saturation pastel palette with organic, non-uniform shape edges
**Not this if**: The product needs sharp, high-contrast, data-dense, or technical presentation.

For deeper technique detail (exact CSS/animation implementation), web-search for "watercolor CSS background design" rather than guessing — this file gives direction, not a full spec.
