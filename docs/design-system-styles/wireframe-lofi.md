# Wireframe / Low-Fi Aesthetic

**When to use**: Early-stage prototypes, internal tools, or products deliberately signaling "unfinished/functional over polished."
**Palette example**: #FFFFFF (bg), #999999 (placeholder gray), #000000 (outline black)
**Typography**: Arial or system-ui (headings and body, deliberately generic)
**Visual traits**:
- Visible gray-box placeholders with diagonal-line "image" markers
- Thin black outline strokes on all elements instead of fills or shadows
- Uses default/unstyled form controls to emphasize structure over finish
**Not this if**: This is a customer-facing production surface that needs to build trust or brand affinity.

For deeper technique detail (exact CSS/animation implementation), web-search for "wireframe lo-fi UI mockup CSS" rather than guessing — this file gives direction, not a full spec.
