# Luxury Real Estate / Architectural

**When to use**: High-end property listings, architecture firms, or interior design portfolios wanting a refined, spatial feel.
**Palette example**: #FFFFFF (bg white), #1A1A1A (charcoal text), #B8A88A (warm stone accent), #3E4C48 (deep sage)
**Typography**: Neue Haas Unica (headings) / Söhne (body)
**Visual traits**:
- Full-bleed high-resolution architectural photography as primary content, minimal overlay text
- Thin, refined sans-serif type with wide letter-spacing on labels/captions
- Grid-based gallery layouts with generous margins, muted natural material color references
**Not this if**: The product is playful, budget, or mass-market — this style signals exclusivity and high price point.

For deeper technique detail (exact CSS/animation implementation), web-search for "luxury real estate architectural CSS design" rather than guessing — this file gives direction, not a full spec.
