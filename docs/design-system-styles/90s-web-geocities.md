# 90s Web (GeoCities)

**When to use**: Ironic/nostalgic personal sites, indie web art projects, or brands leaning into deliberate "so bad it's good" internet history.
**Palette example**: #FF00FF (magenta), #00FF00 (lime), #0000FF (pure blue), #FFFF00 (yellow), #000000 (bg black)
**Typography**: Comic Sans MS (headings), Times New Roman (body) — default browser fonts, unstyled
**Visual traits**:
- Tiled background patterns/textures, animated GIFs (under-construction signs, spinning globes)
- Rainbow horizontal-rule dividers, visitor counters, guestbook widgets
- Clashing saturated colors with no consistent grid; centered blinking/marquee text
**Not this if**: Any context requiring usability, accessibility, or professional credibility.

For deeper technique detail (exact CSS/animation implementation), web-search for "GeoCities 90s web design CSS marquee blink" rather than guessing — this file gives direction, not a full spec.
