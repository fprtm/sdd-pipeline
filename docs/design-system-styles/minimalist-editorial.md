# Minimalist Editorial

**When to use**: SaaS productivity tools and dev tools that want to feel calm, precise, and content-first (Notion, Linear).
**Palette example**: #FFFFFF (bg), #37352F (near-black text), #2383E2 (link/action blue), #EB5757 (soft red status)
**Typography**: Inter (headings and body) / SF Mono or JetBrains Mono (code/labels)
**Visual traits**:
- Single-column, generous white space, minimal chrome
- Thin 1px borders instead of shadows for separation
- Muted, low-saturation status colors used sparingly
**Not this if**: The product needs strong visual branding or emotional/expressive impact.

For deeper technique detail (exact CSS/animation implementation), web-search for "minimalist editorial SaaS UI CSS design" rather than guessing — this file gives direction, not a full spec.
