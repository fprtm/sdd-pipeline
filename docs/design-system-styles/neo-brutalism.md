# Neo-Brutalism

**When to use**: Indie SaaS, Gen-Z consumer apps, and startup landing pages wanting bold, playful defiance of "safe" corporate UI (Gumroad-era style).
**Palette example**: #FFFC00 (acid yellow bg), #000000 (border/text), #FF3EA5 (hot pink), #00FF85 (neon green)
**Typography**: Archivo Black or Space Grotesk (headings) / Helvetica or Inter (body)
**Visual traits**:
- Thick 2-4px black borders on every element, no soft edges
- Hard drop shadows offset in solid black (no blur), often 4-8px
- Saturated, clashing colors with no gradients, flat fills only
**Not this if**: The brand needs to feel premium, subtle, or enterprise-serious.

For deeper technique detail (exact CSS/animation implementation), web-search for "neo-brutalism UI CSS design" rather than guessing — this file gives direction, not a full spec.
