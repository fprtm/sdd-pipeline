# Editorial Luxury (Fashion Magazine)

**When to use**: High-fashion e-commerce, luxury editorial content, or brand sites wanting a Vogue-like sophisticated feel.
**Palette example**: #FFFFFF (bg white), #111111 (ink black), #C9A961 (muted gold accent)
**Typography**: Didot or Canela (headlines) / Times New Roman / Neue Haas Grotesk (body)
**Visual traits**:
- Extreme whitespace, oversized full-bleed photography, minimal chrome around images
- High-contrast serif display type, often set very large with tight tracking
- Asymmetric magazine-style grid layouts, thin hairline rules as dividers
**Not this if**: The product is budget/mass-market or needs a friendly, casual, approachable tone.

For deeper technique detail (exact CSS/animation implementation), web-search for "editorial fashion magazine CSS design" rather than guessing — this file gives direction, not a full spec.
