# Sticker Collage / Gen-Z

**When to use**: Youth-facing social apps, music/festival brands, or playful DTC products targeting Gen-Z audiences.
**Palette example**: #FF6EC7 (hot pink), #C6FF00 (acid lime), #00E5FF (electric cyan), #0D0D0D (near-black bg)
**Typography**: Archivo Black (headings) / Space Mono (body/labels)
**Visual traits**:
- Overlapping die-cut stickers with white borders, drop shadows, slight rotation
- Mixed media: photos, emojis, hand-drawn scribbles, washi-tape textures layered together
- Deliberately "messy" asymmetric grid, elements bleed off edges
**Not this if**: The brand needs to convey trust, authority, or professionalism (finance, healthcare, B2B enterprise).

For deeper technique detail (exact CSS/animation implementation), web-search for "sticker collage CSS design" rather than guessing — this file gives direction, not a full spec.
