# Bento Grid

**When to use**: Product landing pages and feature-showcase sections (post-2023 Apple-style) that need to summarize many features at a glance.
**Palette example**: #FFFFFF (card bg), #F5F5F7 (page bg), #0071E3 (accent blue), #1D1D1F (text)
**Typography**: SF Pro Display (headings) / SF Pro Text (body)
**Visual traits**:
- Modular grid of rounded-corner cards of varying sizes, like a bento box
- Each cell is self-contained: one feature, icon, or stat per card
- Consistent card radius (~20-24px) and consistent gutter spacing
**Not this if**: Content is linear/narrative (long-form reading) rather than modular feature summaries.

For deeper technique detail (exact CSS/animation implementation), web-search for "bento grid layout CSS design" rather than guessing — this file gives direction, not a full spec.
