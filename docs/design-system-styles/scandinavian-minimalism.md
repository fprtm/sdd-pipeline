# Scandinavian Minimalism

**When to use**: Lifestyle, home, wellness, or furniture brands wanting warmth through simplicity, not sterility.
**Palette example**: #FAF7F2 (warm off-white bg), #2E2A25 (soft charcoal text), #A3B18A (sage accent), #D8C3A5 (sand)
**Typography**: Söhne / Futura PT (headings) / Georgia or Freight Text (body)
**Visual traits**:
- Natural material textures (wood, linen) referenced via warm neutrals
- Abundant negative space with light, airy layouts
- Rounded, understated UI elements, no harsh contrast
**Not this if**: The brand is tech-forward, loud, or targets a younger, high-energy audience.

For deeper technique detail (exact CSS/animation implementation), web-search for "Scandinavian minimalism web design CSS" rather than guessing — this file gives direction, not a full spec.
