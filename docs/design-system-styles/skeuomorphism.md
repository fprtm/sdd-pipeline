# Skeuomorphism

**When to use**: Apps simulating a physical tool (notes, calculators, music mixers) where real-world metaphors aid learnability.
**Palette example**: #D9CBA3 (leather tan), #8B6F47 (stitched brown), #F0EAD6 (paper cream), #2B2B2B (shadow)
**Typography**: Chalkboard SE / Marker Felt (headings, sparingly) / Helvetica (body)
**Visual traits**:
- Realistic textures: leather stitching, brushed metal, wood grain, torn paper edges
- Heavy directional shadows and highlights simulating physical depth and light sources
- UI controls mimic real objects (skeuomorphic switches, dials, page-turn curl animations)
**Not this if**: The product targets a modern audience expecting flat/clean UI — this style now reads dated (pre-2013 iOS era).

For deeper technique detail (exact CSS/animation implementation), web-search for "skeuomorphism CSS design" rather than guessing — this file gives direction, not a full spec.
