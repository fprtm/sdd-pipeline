# Gradient Mesh (AI-Gen)

**When to use**: AI product landing pages, startup hero sections wanting a soft, generative, "made by AI" contemporary look.
**Palette example**: #6D28D9 (violet), #EC4899 (magenta), #F59E0B (amber), #0EA5E9 (sky) blended in a mesh gradient
**Typography**: General Sans (headings) / Inter (body)
**Visual traits**:
- Organic multi-color mesh/blob gradients (CSS conic-gradient or SVG feTurbulence) as hero backgrounds
- Soft grain/noise overlay to avoid gradient banding
- Blurred glowing color orbs layered behind glass/flat foreground cards
**Not this if**: The product needs a restrained, corporate, or monochrome brand identity.

For deeper technique detail (exact CSS/animation implementation), web-search for "gradient mesh background CSS design" rather than guessing — this file gives direction, not a full spec.
