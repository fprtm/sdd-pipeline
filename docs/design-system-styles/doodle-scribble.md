# Doodle / Scribble

**When to use**: Education, note-taking, or creative-tool products wanting a hand-crafted, informal, notebook-like feel.
**Palette example**: #2B2B2B (ink black), #FFFCF5 (paper cream), #FF9F1C (marker orange accent)
**Typography**: Kalam (headings/annotations) / Work Sans (body)
**Visual traits**:
- Hand-drawn, imperfect line icons and underlines (looks sketched with a pen, slightly wobbly)
- Marginalia-style annotations: arrows, circles, cross-outs pointing at UI elements
- Loose grid, elements feel placed by hand rather than aligned to a strict system
**Not this if**: The product requires a precise, high-fidelity, or data-dense professional interface.

For deeper technique detail (exact CSS/animation implementation), web-search for "doodle sketch CSS design" rather than guessing — this file gives direction, not a full spec.
