# Kawaii / Cute

**When to use**: Children's products, mascots, journaling/wellness apps, or brands wanting an approachable, adorable tone.
**Palette example**: #FFD1DC (pastel pink), #B5EAD7 (mint), #FFF5BA (butter yellow), #FFFFFF (bg)
**Typography**: Baloo 2 (headings) / Quicksand (body)
**Visual traits**:
- Rounded, chubby shapes with oversized eyes/blush on any character elements
- Pastel palette with soft drop shadows, no harsh contrast
- Small decorative motifs: stars, hearts, sparkles, clouds scattered around content
**Not this if**: The audience is adults seeking authority, technical credibility, or a serious/professional brand.

For deeper technique detail (exact CSS/animation implementation), web-search for "kawaii UI CSS design" rather than guessing — this file gives direction, not a full spec.
