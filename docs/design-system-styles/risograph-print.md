# Risograph Print

**When to use**: Indie zines, cultural/arts organizations, creative studios wanting a bold, retro, limited-palette printmaking look.
**Palette example**: #FF6B9D (riso pink), #0084C8 (riso blue), #FFE800 (riso yellow), #F2EDE4 (uncoated paper bg) — 2-3 ink colors max
**Typography**: Studio Feixen Sans or Archivo Black (headings) / Courier Prime (body)
**Visual traits**:
- Visible misregistration: overlapping flat ink layers slightly offset, creating halftone-edge color fringing
- Limited 2-3 spot-color palette (no gradients, no full CMYK richness) mimicking screen-print limitations
- Grainy halftone dot textures and uneven ink saturation patches within shapes
**Not this if**: The brand needs photorealistic imagery, smooth gradients, or a polished corporate finish.

For deeper technique detail (exact CSS/animation implementation), web-search for "risograph print style CSS design" rather than guessing — this file gives direction, not a full spec.
