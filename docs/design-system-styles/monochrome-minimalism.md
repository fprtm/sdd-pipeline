# Monochrome Minimalism

**When to use**: High-fashion, architecture, or portfolio sites wanting stark, gallery-like sophistication.
**Palette example**: #000000 (black), #FFFFFF (white), #808080 (mid-gray, only tonal variation)
**Typography**: Neue Haas Grotesk (headings) / Times New Roman or Helvetica (body)
**Visual traits**:
- Pure black/white/gray palette with zero hue — color is treated as an intrusion
- Large-scale photography or imagery desaturated to grayscale
- Heavy reliance on contrast and scale for hierarchy instead of color
**Not this if**: The brand needs to signal energy, warmth, or category differentiation through color.
