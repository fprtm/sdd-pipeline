# Data-Dense Dashboard

**When to use**: Trading terminals, observability/monitoring tools, and analytics platforms for expert users who need maximum information per screen.
**Palette example**: #0D1117 (near-black bg), #58A6FF (data blue), #3FB950 (positive green), #F85149 (negative red)
**Typography**: IBM Plex Sans (labels), IBM Plex Mono (numeric/tabular data)
**Visual traits**:
- Dark theme default with high-contrast small-scale typography (11-13px common)
- Dense grids of sparklines, tables, and multi-panel charts with minimal whitespace
- Color reserved strictly for status/direction signaling (green up, red down)
**Not this if**: The audience is non-expert or the product needs generous whitespace for a calm feel.

For deeper technique detail (exact CSS/animation implementation), web-search for "data dense dashboard UI design trading terminal" rather than guessing — this file gives direction, not a full spec.
