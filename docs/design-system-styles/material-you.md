# Material You

**When to use**: Android-first consumer apps or any product wanting Google's dynamic, personalized, accessible design language.
**Palette example**: #6750A4 (primary), #EADDFF (primary container), #21005D (on-primary-container), #FFFBFE (surface) — tonal palette generated from a seed color
**Typography**: Roboto Flex (headings) / Roboto (body)
**Visual traits**:
- Dynamic color extracted from user wallpaper/seed, expressed across tonal roles (primary/secondary/tertiary containers)
- Large, fully-rounded corners (16-28px) on cards, buttons, and FABs
- Elevation via subtle tonal-color shifts rather than heavy shadows; generous whitespace
**Not this if**: Building for iOS-only or a brand with fixed, non-adaptive brand colors (Material You expects per-user dynamic theming).

For deeper technique detail (exact CSS/animation implementation), web-search for "Material You design system" rather than guessing — this file gives direction, not a full spec.
