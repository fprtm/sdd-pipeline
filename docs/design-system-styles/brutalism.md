# Brutalism

**When to use**: Portfolios, art collectives, or anti-corporate brands wanting to signal rawness and rejection of polish.
**Palette example**: #FFFFFF (bg), #000000 (text), #C0C0C0 (system gray, unstyled feel)
**Typography**: Times New Roman or Courier New (headings and body, deliberately unstyled)
**Visual traits**:
- Default browser styling exposed on purpose: blue underlined links, system fonts
- Harsh, unaligned grid breaks and overlapping elements
- No rounded corners, no shadows, no transitions
**Not this if**: The product needs to feel approachable, trustworthy, or conversion-optimized for a mainstream audience.

For deeper technique detail (exact CSS/animation implementation), web-search for "brutalist web design CSS" rather than guessing — this file gives direction, not a full spec.
