# Nordic Noir / Dark Minimal

**When to use**: Developer tools, security products, or premium dark-mode-first apps wanting a moody, focused, high-contrast feel.
**Palette example**: #0D1117 (near-black bg), #C9D1D9 (cool gray text), #58A6FF (icy blue accent), #F85149 (alert red)
**Typography**: IBM Plex Sans (headings) / IBM Plex Mono (body/code)
**Visual traits**:
- Deep charcoal/near-black backgrounds, never pure black
- Cool, desaturated blue-gray palette evoking Scandinavian winter light
- High-contrast single accent for interactive elements only
**Not this if**: The brand needs to feel warm, playful, or optimistic.

For deeper technique detail (exact CSS/animation implementation), web-search for "dark mode minimal UI CSS design" rather than guessing — this file gives direction, not a full spec.
