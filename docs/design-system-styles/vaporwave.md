# Vaporwave

**When to use**: Music, art, and nostalgic entertainment brands wanting a dreamy, ironic 80s/90s digital-consumerism aesthetic.
**Palette example**: #FF71CE (hot pink), #01CDFE (cyan), #05FFA1 (mint), #B967FF (purple), #1A0F2E (deep purple-black bg)
**Typography**: VCR OSD Mono / Windows 95-era system fonts (headings), any generic sans for body
**Visual traits**:
- Pink/cyan gradient skies with grid horizons, low-poly palm trees, and Greco-Roman statue busts
- Glitch artifacts, VHS scanlines, chromatic aberration overlays
- Retro tech ephemera: old Windows UI chrome, floppy disks, dolphins
**Not this if**: The brand needs to be taken seriously as corporate, financial, or enterprise-grade.

For deeper technique detail (exact CSS/animation implementation), web-search for "vaporwave aesthetic CSS glitch VHS design" rather than guessing — this file gives direction, not a full spec.
