# Dark Academia

**When to use**: Literary, education, bookshop, or intellectual-community brands wanting a moody, scholarly, gothic-library feel.
**Palette example**: #3B2A20 (aged leather brown), #1C1C1C (near-black), #6E7C5A (library moss green), #C9B896 (parchment)
**Typography**: Playfair Display (headings) / Crimson Text (body)
**Visual traits**:
- Rich brown/burgundy/forest-green palette evoking old libraries, leather, candlelight
- Serif typography throughout, often with drop caps and classical ornamentation
- Textured backgrounds (aged paper, wood grain), vintage engraving-style illustrations
**Not this if**: The brand needs a bright, energetic, or futuristic-tech feel — this palette reads heavy and slow.

For deeper technique detail (exact CSS/animation implementation), web-search for "dark academia CSS design" rather than guessing — this file gives direction, not a full spec.
