# Punk / Zine Aesthetic

**When to use**: Independent media, activist campaigns, or subculture brands wanting a cut-and-paste, anti-establishment voice.
**Palette example**: #FFFFFF (photocopy bg), #000000 (ink), #FF0000 (protest red)
**Typography**: Ransom-note mixed faces (Impact + handwritten marker fonts) for headings / typewriter font (body)
**Visual traits**:
- Cut-out ransom-note lettering with mismatched fonts and sizes
- Photocopied, high-contrast, low-fidelity image treatment
- Hand-scrawled annotations, tape marks, staple/photocopier artifacts
**Not this if**: The brand needs to feel polished, trustworthy, or enterprise-grade.

For deeper technique detail (exact CSS/animation implementation), web-search for "punk zine aesthetic web design CSS" rather than guessing — this file gives direction, not a full spec.
