# Fluent Design

**When to use**: Windows desktop apps and Microsoft 365-adjacent tools wanting a light, layered, productivity-focused feel.
**Palette example**: #0078D4 (Microsoft blue), #F3F2F1 (neutral light bg), #201F1E (neutral dark text)
**Typography**: Segoe UI Variable (headings and body)
**Visual traits**:
- Acrylic/mica translucent surfaces with background blur ("reveal" material)
- Subtle depth via light borders and soft shadows rather than heavy elevation
- Connected animations between views; light, airy spacing with rounded 4px corners
**Not this if**: Targeting mobile-first or non-Windows platforms where the acrylic/blur idiom feels out of place.

For deeper technique detail (exact CSS/animation implementation), web-search for "Fluent Design System CSS acrylic mica" rather than guessing — this file gives direction, not a full spec.
