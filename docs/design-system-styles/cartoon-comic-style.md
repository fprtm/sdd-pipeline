# Cartoon / Comic Style

**When to use**: Gaming, entertainment, or consumer apps wanting an energetic, narrative-driven feel.
**Palette example**: #FFDE00 (comic yellow), #E4002B (action red), #0057B8 (panel blue), #000000 (ink outline)
**Typography**: Bangers (headlines/callouts) / Nunito (body)
**Visual traits**:
- Bold black ink outlines on every shape, flat cel-shaded color fills
- Halftone dot patterns (Ben-Day dots) for shading and texture
- Speech bubbles, motion lines, onomatopoeia ("POW", "BOOM") as UI accents
**Not this if**: The audience is enterprise/B2B or the product requires a serious, minimal tone.

For deeper technique detail (exact CSS/animation implementation), web-search for "comic book CSS design" rather than guessing — this file gives direction, not a full spec.
