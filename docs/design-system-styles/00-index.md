# Design System Styles — Index

Fallback style catalog used when the `ui-ux-pro-max` plugin is not installed. Scan this index, match the project brief against the keywords, then open **only the 1-3 relevant style files** — never read all of these into context at once. Each linked file is short (~15 lines): when-to-use, palette, typography, visual traits, when NOT to use.
