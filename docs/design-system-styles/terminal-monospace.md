# Terminal / Monospace Aesthetic

**When to use**: Developer tools, CLIs, technical documentation sites, hacker-culture or retro-computing brands.
**Palette example**: #0A0E14 (terminal bg), #39FF14 (phosphor green text), #FFB86C (amber warning), #6272A4 (comment gray)
**Typography**: JetBrains Mono (headings) / IBM Plex Mono (body)
**Visual traits**:
- Blinking block cursor, ASCII/box-drawing dividers
- Fixed-width grid alignment everywhere, no proportional fonts
- Prompt-style prefixes ($, >, #) and command-line framing for UI copy
**Not this if**: Targeting non-technical consumers or a brand needing warmth and approachability.

For deeper technique detail (exact CSS/animation implementation), web-search for "terminal monospace UI CSS design" rather than guessing — this file gives direction, not a full spec.
