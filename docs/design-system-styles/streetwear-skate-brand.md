# Streetwear / Skate Brand

**When to use**: Apparel, sneaker, or youth lifestyle brands wanting a raw, rebellious urban identity.
**Palette example**: #000000 (bg black), #FFFFFF (contrast white), #FF3B00 (safety orange accent)
**Typography**: Helvetica Neue Condensed Bold (headings) / Courier Prime (body/tags)
**Visual traits**:
- Grunge/spray-paint textures, distressed edges, torn-paper or tape overlays
- Bold stamp/patch-style logos, box logos, screen-print registration marks (misaligned CMYK offset)
- Diagonal/stacked type layouts, high-contrast black and white with one loud accent color
**Not this if**: The brand needs to feel polished, corporate, or luxury — grit is the point here, refinement kills it.

For deeper technique detail (exact CSS/animation implementation), web-search for "streetwear skate brand CSS design" rather than guessing — this file gives direction, not a full spec.
