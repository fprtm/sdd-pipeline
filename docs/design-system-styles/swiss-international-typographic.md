# Swiss / International Typographic Style

**When to use**: Institutional, editorial, or B2B products that need clarity, authority, and zero decoration.
**Palette example**: #FFFFFF (white bg), #000000 (black text), #FF0000 (signal red accent)
**Typography**: Helvetica Now / Akzidenz-Grotesk (headings and body, same family throughout)
**Visual traits**:
- Strict grid with visible baseline alignment and generous margins
- Flush-left, ragged-right text; no centered type
- Sparse use of a single accent color for hierarchy, not decoration
**Not this if**: The brand needs warmth, playfulness, or emotional/human texture.

For deeper technique detail (exact CSS/animation implementation), web-search for "Swiss International Typographic Style CSS design" rather than guessing — this file gives direction, not a full spec.
