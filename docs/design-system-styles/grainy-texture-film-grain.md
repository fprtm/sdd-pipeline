# Grainy Texture / Film Grain

**When to use**: Music, fashion, photography, or lifestyle brands wanting a nostalgic, analog, editorial-cool aesthetic over flat digital gradients.
**Palette example**: #1A1A1A (near-black bg), #F5F0E8 (warm off-white), #D4A574 (film-warm amber), #8B4049 (muted burgundy accent)
**Typography**: Suisse Int'l (headings) / Times New Roman or PP Editorial New (body, editorial serif)
**Visual traits**:
- Fine animated or static noise overlay (SVG feTurbulence / grain PNG) at 4-8% opacity across all surfaces
- Slightly desaturated, warm-shifted "35mm film" color grading on gradients and photos
- Subtle vignette darkening at frame edges
**Not this if**: The UI is data-dense or needs pixel-crisp clarity — grain adds visual noise that hurts legibility at small sizes.

For deeper technique detail (exact CSS/animation implementation), web-search for "grainy film grain texture CSS design" rather than guessing — this file gives direction, not a full spec.
