# Bauhaus

**When to use**: Design-forward brands, art/architecture institutions, and modernist product lines wanting functional geometric purity.
**Palette example**: #E30613 (primary red), #FFD500 (primary yellow), #005CA9 (primary blue), #FFFFFF (bg), #1A1A1A (black)
**Typography**: Futura / Bauhaus 93 (display headings), Univers (body)
**Visual traits**:
- Primary-color geometric shapes (circle, square, triangle) as core visual vocabulary
- Asymmetric grid layouts with strong diagonal or orthogonal composition
- Function-first typography, no ornamentation, thick rule lines as dividers
**Not this if**: The brand needs a soft, organic, or luxury-decorative feel.

For deeper technique detail (exact CSS/animation implementation), web-search for "Bauhaus design CSS primary colors geometric" rather than guessing — this file gives direction, not a full spec.
