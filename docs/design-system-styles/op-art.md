# Op Art

**When to use**: Design-forward brands, art galleries, or products wanting a striking optical-illusion visual signature.
**Palette example**: #000000 (black), #FFFFFF (white), occasional #FF0000 (red pulse accent, used sparingly)
**Typography**: Futura or Eurostile (headings) / Helvetica (body)
**Visual traits**:
- High-contrast black-and-white geometric patterns (stripes, moiré, concentric circles) that create movement illusions
- Precise mathematical repetition and symmetry, no organic shapes
- Color used minimally and only to disrupt the optical pattern, never for decoration
**Not this if**: The interface has dense text or functional UI where visual vibration would hurt readability/accessibility.

For deeper technique detail (exact CSS/animation implementation), web-search for "op art optical illusion web design CSS" rather than guessing — this file gives direction, not a full spec.
