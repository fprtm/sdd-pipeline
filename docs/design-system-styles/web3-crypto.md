# Web3 / Crypto Aesthetic

**When to use**: DeFi platforms, NFT marketplaces, DAO tools, blockchain wallets wanting a bold, trustless-but-slick tech-native feel.
**Palette example**: #0B0F19 (dark navy bg), #6366F1 (indigo primary), #22D3EE (cyan accent), #FACC15 (gold highlight)
**Typography**: Space Grotesk (headings) / IBM Plex Sans (body)
**Visual traits**:
- Dark-mode-first with vivid indigo/cyan gradient CTAs and glowing button edges
- Abstract geometric/wireframe node-and-line network motifs (blockchain visual metaphor)
- Card-based layouts with subtle gradient borders and monospace numeric data (wallet addresses, token amounts)
**Not this if**: Targeting a mainstream non-crypto-native audience wary of speculative finance visual cues.

For deeper technique detail (exact CSS/animation implementation), web-search for "web3 crypto UI CSS design" rather than guessing — this file gives direction, not a full spec.
