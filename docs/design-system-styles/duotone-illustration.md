# Duotone Illustration

**When to use**: Tech/startup marketing sites and editorial pieces wanting a bold, modern illustrative look with minimal color complexity.
**Palette example**: #FF3366 (hot pink shadow), #1B1F3B (deep navy shadow), #FFF8E7 (cream highlight)
**Typography**: Söhne (headings) / Inter (body)
**Visual traits**:
- Photos/illustrations mapped to exactly two tones (shadow + highlight), no midtones
- High contrast, poster-like flattening of imagery
- Often paired with a single accent color for CTAs, rest kept strictly duotone
**Not this if**: The product needs realistic photography or nuanced color communication (e.g. e-commerce product shots).

For deeper technique detail (exact CSS/animation implementation), web-search for "duotone illustration CSS design" rather than guessing — this file gives direction, not a full spec.
