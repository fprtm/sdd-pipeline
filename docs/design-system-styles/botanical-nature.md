# Botanical / Nature-Inspired

**When to use**: Skincare, wellness, sustainable/eco brands, plant-based products wanting an organic, grounded, earthy identity.
**Palette example**: #4A5D3A (forest green), #E8DCC8 (sand beige), #C17A4E (terracotta), #7D9471 (sage accent)
**Typography**: Fraunces (headings, warm serif) / Karla (body)
**Visual traits**:
- Line-art botanical illustrations (leaves, ferns, branches) as decorative borders and dividers
- Earthy muted-green and terracotta palette, matte finishes, no neon or high-saturation colors
- Natural texture overlays (linen, kraft) and asymmetric organic layout framing
**Not this if**: The brand is tech/finance/urban and needs a synthetic, precise, high-tech visual language.

For deeper technique detail (exact CSS/animation implementation), web-search for "botanical nature-inspired CSS design" rather than guessing — this file gives direction, not a full spec.
