# Vintage Letterpress

**When to use**: Craft goods, print shops, coffee/bakery brands, or heritage products wanting a tactile, artisanal print feel.
**Palette example**: #FAF3E0 (cotton paper), #2E2A26 (letterpress ink black), #A13D3D (oxblood red accent)
**Typography**: Freight Text (headings) / American Typewriter (body)
**Visual traits**:
- Debossed/inked-impression look — subtle inset shadow simulating pressed type into paper
- Limited 2-3 color palette mimicking single/spot-color print runs
- Ornamental borders, rules, and badge/seal-style emblems typical of old print shops
**Not this if**: The brand needs a digital-native, high-tech, or futuristic feel — this style intentionally evokes pre-digital craft.

For deeper technique detail (exact CSS/animation implementation), web-search for "vintage letterpress CSS design" rather than guessing — this file gives direction, not a full spec.
