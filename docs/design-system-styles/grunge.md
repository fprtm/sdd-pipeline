# Grunge

**When to use**: Music, streetwear, or alt-culture brands wanting a distressed, rebellious, DIY texture.
**Palette example**: #1A1A1A (soot black), #6B6B5A (muddy olive), #E8E2D0 (dirty paper), #8B0000 (dried-blood red)
**Typography**: Rough-edged display faces like "Rift" or "League Gothic" (headings) / Courier or typewriter font (body)
**Visual traits**:
- Torn-paper, ink-splatter, and photocopy-noise textures layered over content
- Distressed/scratched type with irregular baselines
- Muted, desaturated palette punctuated by one raw accent color
**Not this if**: The brand needs to feel clean, corporate, or accessible to a broad mainstream audience.

For deeper technique detail (exact CSS/animation implementation), web-search for "grunge web design texture CSS" rather than guessing — this file gives direction, not a full spec.
