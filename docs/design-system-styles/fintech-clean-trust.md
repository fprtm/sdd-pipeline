# Fintech Clean / Trust Design

**When to use**: Banking, payments, and investing apps that must feel secure, modern, and trustworthy at a glance.
**Palette example**: #0A2540 (deep trust navy), #635BFF (Stripe-style violet accent), #FFFFFF (clean bg), #00D4B4 (mint confirm)
**Typography**: Söhne / General Sans (headings), Inter (body and numerals)
**Visual traits**:
- Generous whitespace with crisp 1px hairline dividers, almost no drop shadows
- Large, confident numerals for balances/amounts with tabular figure alignment
- Gradient accents used sparingly on hero sections only, flat elsewhere
**Not this if**: The brand wants to feel playful, artisanal, or budget/low-trust category (e.g. discount retail).

For deeper technique detail (exact CSS/animation implementation), web-search for "fintech clean trust UI design Stripe Mercury" rather than guessing — this file gives direction, not a full spec.
