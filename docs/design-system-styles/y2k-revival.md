# Y2K Revival

**When to use**: Gen-Z fashion, music, and lifestyle brands wanting nostalgic early-2000s tech-optimism energy.
**Palette example**: #C0C0C0 (chrome silver), #FF00FF (magenta), #00FFFF (cyber cyan), #EAEAEA (bg)
**Typography**: Eurostile / Orbitron (headings), Arial (body, deliberately plain-web era)
**Visual traits**:
- Chrome/metallic gradients, glossy bubble buttons with specular highlights
- Blob shapes, translucent plastic ("frosted iMac") panels, flame/star motifs
- Low-res pixel accents mixed with glossy 3D renders
**Not this if**: The brand needs to feel timeless, minimal, or enterprise-serious.

For deeper technique detail (exact CSS/animation implementation), web-search for "Y2K aesthetic CSS chrome gradient design" rather than guessing — this file gives direction, not a full spec.
