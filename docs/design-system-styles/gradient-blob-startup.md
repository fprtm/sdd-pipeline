# Gradient Blob Startup

**When to use**: SaaS/tech startup landing pages wanting a friendly, modern, "Web 2.5" feel without going fully corporate-flat.
**Palette example**: #6D5DFC (violet), #FF6584 (coral pink), #00D9C0 (mint), #FFFFFF (bg)
**Typography**: Cabinet Grotesk (headings) / Inter (body)
**Visual traits**:
- Large soft-edged organic blob shapes as background decoration, often blurred (gaussian blur 40-80px)
- Smooth multi-stop linear/radial gradients (violet-to-pink-to-teal) behind glassy UI cards
- Rounded corners everywhere (16-24px radius), floating 3D-ish isometric illustrations
**Not this if**: The brand needs to feel established, serious, or premium/luxury — this style reads as "early-stage startup."

For deeper technique detail (exact CSS/animation implementation), web-search for "gradient blob CSS design" rather than guessing — this file gives direction, not a full spec.
