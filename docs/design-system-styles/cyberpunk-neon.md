# Cyberpunk Neon

**When to use**: Gaming platforms, hacker/security tools, futuristic entertainment brands wanting rebellious high-energy tech vibes.
**Palette example**: #0D0221 (near-black bg), #FF2E63 (hot pink neon), #08F7FE (electric cyan), #F9F002 (acid yellow accent)
**Typography**: Orbitron (headings) / Rajdhani (body)
**Visual traits**:
- Glowing neon edges via layered box-shadow/text-shadow blur
- Dark backgrounds with scanline or CRT-noise overlays
- High-contrast magenta/cyan duotone lighting, chromatic aberration on hover
**Not this if**: The brand needs to feel trustworthy, calm, or enterprise-conservative (finance, healthcare, legal).

For deeper technique detail (exact CSS/animation implementation), web-search for "cyberpunk neon CSS design" rather than guessing — this file gives direction, not a full spec.
