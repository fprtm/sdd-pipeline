# 8-Bit / Pixel Art

**When to use**: Indie games, retro-gaming brands, and playful developer tools wanting nostalgic console-era charm.
**Palette example**: #212529 (near-black outline), #FF004D (NES red), #29ADFF (NES blue), #FFEC27 (NES yellow)
**Typography**: Press Start 2P (headings/UI), VT323 (body/monospace fallback)
**Visual traits**:
- Hard-edged pixel grid with no anti-aliasing, visible square pixel blocks
- Limited color palette (4-16 colors) mimicking NES/Game Boy hardware constraints
- Chunky UI elements: rectangular buttons with thick pixel borders, no gradients
**Not this if**: The brand needs to feel premium, professional, or high-resolution/photorealistic.

For deeper technique detail (exact CSS/animation implementation), web-search for "pixel art 8-bit UI CSS image-rendering pixelated" rather than guessing — this file gives direction, not a full spec.
