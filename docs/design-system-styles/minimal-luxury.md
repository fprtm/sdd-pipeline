# Minimal Luxury (Apple-Esque)

**When to use**: Premium tech products, flagship hardware/software marketing sites wanting precision and restraint.
**Palette example**: #FFFFFF (bg white), #1D1D1F (near-black text), #0071E3 (system blue accent), #F5F5F7 (light gray panel)
**Typography**: SF Pro Display (headings) / SF Pro Text (body)
**Visual traits**:
- Vast whitespace, single hero product shot per section, no visual clutter
- Subtle depth via soft shadows and blur (frosted glass/vibrancy), never flat drop shadows
- Precise 8pt-grid spacing, thin font weights for large display type, understated micro-interactions
**Not this if**: The brand needs to feel warm, handmade, or maximalist — this style is deliberately cold and engineered.

For deeper technique detail (exact CSS/animation implementation), web-search for "minimal luxury Apple-style CSS design" rather than guessing — this file gives direction, not a full spec.
