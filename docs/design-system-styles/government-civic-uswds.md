# Government / Civic Design (USWDS)

**When to use**: Government portals, civic services, and public-sector tools requiring accessibility compliance and plain-language clarity.
**Palette example**: #005EA2 (USWDS primary blue), #1B1B1B (ink text), #F0F0F0 (light gray bg), #D63E04 (error red)
**Typography**: Public Sans (headings and body), Merriweather (long-form reading content)
**Visual traits**:
- High-contrast text meeting WCAG AA/AAA, large touch targets, visible focus outlines
- Boxy, unadorned banner/header with official seals and ".gov" identity markers
- Minimal iconography, functional forms with clear error states and plain labels
**Not this if**: Building a consumer brand where personality and visual flair matter more than compliance and universal usability.

For deeper technique detail (exact CSS/animation implementation), web-search for "U.S. Web Design System USWDS CSS components" rather than guessing — this file gives direction, not a full spec.
