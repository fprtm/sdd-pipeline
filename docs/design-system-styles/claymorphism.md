# Claymorphism

**When to use**: Playful consumer apps, kids' education tools, mobile games wanting a squishy, 3D, toy-like friendly interface.
**Palette example**: #FFE5EC (soft pink bg), #A78BFA (clay purple), #6EE7B7 (clay mint), #FFFFFF (highlight)
**Typography**: Baloo 2 (headings) / Quicksand (body)
**Visual traits**:
- Puffy 3D elements via inset + outset dual shadows creating a molded-clay bulge
- Very rounded corners (24-40px), pastel saturated colors, matte (non-glossy) finish
- Thick soft drop shadow below each element plus subtle inner highlight for "squishable" depth
**Not this if**: The brand needs to feel sleek, minimal, or professional — claymorphism is inherently playful and toy-like.

For deeper technique detail (exact CSS/animation implementation), web-search for "claymorphism CSS design" rather than guessing — this file gives direction, not a full spec.
