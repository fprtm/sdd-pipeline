# Children's Book Illustration

**When to use**: Kids' education apps, toy brands, or family-oriented products wanting a warm, storybook feel.
**Palette example**: #F4A261 (warm sand), #2A9D8F (soft teal), #E76F51 (terracotta), #FEFAE0 (page cream bg)
**Typography**: Baloo 2 (headings) / Lato (body)
**Visual traits**:
- Soft textured brush/watercolor fills with visible paper grain, not flat vector
- Rounded, friendly character proportions with simple expressive faces
- Muted-but-warm earthy palette rather than saturated primaries
**Not this if**: The audience is adults needing a modern tech or corporate look — texture reads as juvenile.

For deeper technique detail (exact CSS/animation implementation), web-search for "children's book illustration CSS design" rather than guessing — this file gives direction, not a full spec.
