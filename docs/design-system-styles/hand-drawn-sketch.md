# Hand-Drawn / Sketch

**When to use**: Indie products, creative agencies, education tools wanting an authentic, informal, human-made feel over polished digital slickness.
**Palette example**: #FAF7F0 (paper bg), #2B2B2B (ink black), #E85D4C (marker red accent), #4A7C6F (marker green accent)
**Typography**: Caveat or Kalam (headings, handwritten) / Helvetica Neue (body, for readability contrast)
**Visual traits**:
- Wobbly/imperfect hand-drawn borders and underlines (SVG rough.js-style jittery strokes)
- Doodle icons and arrows instead of polished vector icon sets
- Slight rotation/skew on cards mimicking pinned or taped paper notes
**Not this if**: The brand needs to project precision, scale, or enterprise-grade trust.

For deeper technique detail (exact CSS/animation implementation), web-search for "hand-drawn sketch UI CSS design" rather than guessing — this file gives direction, not a full spec.
