# Corporate Memphis

**When to use**: Startup landing pages, HR/fintech onboarding flows, and SaaS marketing sites wanting to feel friendly and approachable.
**Palette example**: #6C5CE7 (soft violet), #FF7675 (peach coral), #FDCB6E (warm yellow), #F5F3FF (lavender bg)
**Typography**: Circular / Poppins (headings), Inter (body)
**Visual traits**:
- Flat, limbless illustrated humans with disproportionate limbs and neutral skin-tone gradients
- Rounded, oversized shapes with no hard shadows, only soft ambient blobs
- Pastel-saturated palette with high contrast against white/off-white backgrounds
**Not this if**: The brand needs to feel serious, technical, luxury, or emotionally authentic — this style is widely criticized as generic and impersonal.

For deeper technique detail (exact CSS/animation implementation), web-search for "Corporate Memphis Alegria illustration style" rather than guessing — this file gives direction, not a full spec.
