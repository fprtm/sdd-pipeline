# Enterprise SaaS Dashboard

**When to use**: B2B admin panels, internal tools, and subscription software where clarity and trust matter more than personality.
**Palette example**: #1E293B (slate navy), #2563EB (action blue), #F8FAFC (neutral bg), #10B981 (success green)
**Typography**: Inter (headings and body), JetBrains Mono (data/code snippets)
**Visual traits**:
- Left sidebar nav + top bar layout with card-based content panels
- Restrained color use: one primary accent, neutral grays everywhere else
- 8px-grid spacing, subtle 1px borders instead of heavy shadows
**Not this if**: The product is consumer-facing and needs emotional or playful branding.

For deeper technique detail (exact CSS/animation implementation), web-search for "enterprise SaaS dashboard UI design system" rather than guessing — this file gives direction, not a full spec.
