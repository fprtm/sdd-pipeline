# Generative Art / Algorithmic

**When to use**: Creative-coding portfolios, music/art platforms, experimental brand sites wanting an ever-changing, procedural visual identity.
**Palette example**: #111111 (canvas bg), #FF3366 (procedural accent), #33FFCC (procedural accent 2), palette often randomized per session
**Typography**: Neue Montreal (headings) / Söhne Mono (data/code captions)
**Visual traits**:
- Canvas/WebGL-driven particle fields, flow fields, or Perlin-noise-based patterns unique per load
- Algorithmic symmetry: recursive shapes, cellular automata grids, voronoi/delaunay tessellations
- Interactive elements react to cursor/scroll (parameters feed back into the generative system)
**Not this if**: The brand needs a fixed, predictable, easily-reproducible visual identity or fast load times on low-power devices.

For deeper technique detail (exact CSS/animation implementation), web-search for "generative art algorithmic design canvas CSS" rather than guessing — this file gives direction, not a full spec.
