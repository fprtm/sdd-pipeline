# Organic / Blob Shapes

**When to use**: Wellness, children's products, community platforms wanting a friendly, soft, non-geometric approachable look.
**Palette example**: #FFF4E0 (cream bg), #FF6B6B (coral blob), #4ECDC4 (teal blob), #FFD93D (yellow accent)
**Typography**: Fredoka (headings) / Nunito (body)
**Visual traits**:
- Irregular blob shapes (SVG border-radius or path morphing) instead of rectangles/circles
- Blobs used as image masks, background decoration, or button/card container shapes
- Gentle floating/morphing animation on blobs (slow scale + border-radius keyframes)
**Not this if**: Enterprise, legal, or financial contexts where precision and formality matter more than warmth.

For deeper technique detail (exact CSS/animation implementation), web-search for "organic blob shapes CSS design" rather than guessing — this file gives direction, not a full spec.
