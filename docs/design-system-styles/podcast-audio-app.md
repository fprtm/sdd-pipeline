# Podcast / Audio App Aesthetic

**When to use**: Podcast platforms, music streaming, or voice-note apps needing a warm, personality-driven "listen now" feel.
**Palette example**: #121212 (studio black bg), #1DB954 (spotify-esque green accent), #FF5A5F (warm coral highlight)
**Typography**: Circular (headings) / Söhne (body)
**Visual traits**:
- Large square cover-art thumbnails with soft shadow, dominant hero art per episode/show
- Waveform visualizers and scrubber bars as primary interactive motif
- Dark-mode-first UI with vibrant accent color extracted from artwork ("dynamic color" theming)
**Not this if**: The product is text/document-centric with no audio or visual media focus.

For deeper technique detail (exact CSS/animation implementation), web-search for "podcast audio app UI CSS design" rather than guessing — this file gives direction, not a full spec.
