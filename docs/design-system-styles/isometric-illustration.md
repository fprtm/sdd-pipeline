# Isometric Illustration

**When to use**: B2B SaaS explainer sections, onboarding illustrations, tech landing pages wanting a friendly "how it works" visual system.
**Palette example**: #4C6FFF (primary blue), #FF7A59 (warm coral), #2EC4B6 (teal), #F4F5F7 (light neutral bg)
**Typography**: Poppins (headings) / Source Sans 3 (body)
**Visual traits**:
- 30-degree isometric projection for objects, servers, devices, and characters
- Flat-shaded geometric shapes with subtle gradient or single drop-shadow for depth
- Consistent light source (top-left) casting soft shadows beneath floating elements
**Not this if**: The product needs realistic photography or a serious/austere enterprise tone.

For deeper technique detail (exact CSS/animation implementation), web-search for "isometric illustration design style" rather than guessing — this file gives direction, not a full spec.
