# Psychedelic

**When to use**: Music festivals, cannabis brands, or experimental art projects wanting trippy, 60s-revival sensory intensity.
**Palette example**: #FF00FF (magenta), #00FFFF (cyan), #FF6D00 (acid orange), #7B2FFF (ultraviolet)
**Typography**: Cooper Black or custom bubble/wavy display type (headings) / Helvetica (body, kept legible)
**Visual traits**:
- Swirling, warped, liquid-distortion shapes and melting typography
- Highly saturated, fluorescent color combinations with high vibration/contrast
- Kaleidoscopic or radiating symmetrical patterns as backgrounds
**Not this if**: The product needs calm readability or a professional/enterprise tone.

For deeper technique detail (exact CSS/animation implementation), web-search for "psychedelic web design CSS" rather than guessing — this file gives direction, not a full spec.
