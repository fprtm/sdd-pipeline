# Biophilic Design

**When to use**: Architecture/real-estate, corporate wellness, sustainability-forward products wanting a calm, human-centered, nature-integrated feel.
**Palette example**: #6B8E5A (living green), #D9CBB8 (natural stone), #3D3229 (bark brown), #F7F5F0 (daylight white)
**Typography**: Public Sans (headings) / Source Serif 4 (body)
**Visual traits**:
- Natural material textures (wood grain, stone, water ripple) used as section backgrounds/imagery, not flat color
- Generous whitespace and asymmetric layouts echoing natural, non-grid arrangements
- Photography-forward with daylight-toned color grading and living-plant imagery over icons/illustration
**Not this if**: The brand is digital-native/tech and needs a synthetic, high-tech, screen-optimized visual language.

For deeper technique detail (exact CSS/animation implementation), web-search for "biophilic design UI CSS" rather than guessing — this file gives direction, not a full spec.
