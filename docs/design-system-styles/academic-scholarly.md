# Academic / Scholarly

**When to use**: Research tools, journals, documentation sites, or institutions needing to signal rigor and trustworthiness.
**Palette example**: #FFFFFF (bg), #1B1B1B (text), #8C1515 (Stanford-cardinal-style accent), #4A4A4A (caption gray)
**Typography**: Source Serif Pro or Libre Caslon (headings/body) / Source Sans Pro (captions, UI labels)
**Visual traits**:
- Dense, structured text with footnotes, citations, and numbered sections
- Serif body text optimized for long-form reading, narrow measure (~65ch)
- Understated single accent color for links/headers, no decorative flourish
**Not this if**: The audience needs quick scanning or a playful/consumer-friendly tone.

For deeper technique detail (exact CSS/animation implementation), web-search for "academic scholarly web typography CSS" rather than guessing — this file gives direction, not a full spec.
