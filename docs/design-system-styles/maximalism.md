# Maximalism

**When to use**: Fashion, entertainment, or lifestyle brands wanting sensory abundance and "more is more" personality.
**Palette example**: #FF6B35 (tangerine), #7209B7 (violet), #F72585 (magenta), #FFD60A (gold), #003049 (deep navy anchor)
**Typography**: Cooper Black or Recoleta (headings) / Poppins (body)
**Visual traits**:
- Layered patterns, textures, and imagery competing for attention deliberately
- Multiple accent colors used simultaneously rather than one restrained palette
- Dense compositions with little unused white space
**Not this if**: The product requires quick scanning, accessibility-first clarity, or a calm/professional tone.

For deeper technique detail (exact CSS/animation implementation), web-search for "maximalist web design CSS" rather than guessing — this file gives direction, not a full spec.
