# Flat Design

**When to use**: Consumer apps and dashboards wanting a clean, fast-loading UI without skeuomorphic depth (post-2013 Microsoft/Google style).
**Palette example**: #2C3E50 (midnight blue), #3498DB (peter river blue), #E74C3C (alizarin red), #ECF0F1 (clouds bg)
**Typography**: Segoe UI / Roboto (headings and body)
**Visual traits**:
- No gradients, shadows, bevels, or textures — solid fills only
- Simple geometric iconography with uniform stroke weight
- Bold, saturated "flat UI" color palette with high contrast
**Not this if**: The brand wants tactile realism, depth cues, or a premium/tactile feel (use neumorphism/skeuomorphism instead).

For deeper technique detail (exact CSS/animation implementation), web-search for "flat design UI CSS" rather than guessing — this file gives direction, not a full spec.
