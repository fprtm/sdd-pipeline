# Sci-Fi HUD

**When to use**: Dashboards, control panels, monitoring tools, or games wanting a spacecraft/mission-control command-center feel.
**Palette example**: #001219 (deep space bg), #94D2BD (hud teal), #EE9B00 (alert amber), #E9D8A6 (readout text)
**Visual traits**:
- Angular clipped-corner panels (clip-path polygons), thin glowing 1-2px borders
- Radial/reticle overlays, crosshair markers, rotating scan-line arcs
- Data readouts in segmented/tabular numeric displays with tick-mark gauges
**Typography**: Eurostile / Michroma (headings) / Share Tech Mono (data readouts)
**Not this if**: The product is consumer-friendly or needs a soft, human, non-technical tone.

For deeper technique detail (exact CSS/animation implementation), web-search for "sci-fi HUD interface CSS design" rather than guessing — this file gives direction, not a full spec.
