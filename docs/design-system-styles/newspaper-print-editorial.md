# Newspaper / Print Editorial

**When to use**: News, long-form journalism, and publications wanting credibility and a tactile print heritage.
**Palette example**: #FDFBF7 (newsprint bg), #1A1A1A (ink black), #B0242F (masthead red)
**Typography**: Tiempos Headline / Freight Display (headlines) / Georgia (body serif)
**Visual traits**:
- Multi-column layouts with hairline rules dividing sections
- Large drop caps and bold, condensed headline type
- Byline/dateline conventions, justified body text
**Not this if**: The product is a fast-scrolling consumer app or needs a modern tech feel.

For deeper technique detail (exact CSS/animation implementation), web-search for "newspaper print editorial web design CSS" rather than guessing — this file gives direction, not a full spec.
