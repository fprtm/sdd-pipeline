# Disco / 70s Groovy

**When to use**: Music festivals, nightlife brands, and lifestyle products wanting warm, energetic retro funk personality.
**Palette example**: #E8722C (burnt orange), #F2C744 (mustard gold), #8B3A62 (magenta-plum), #3D2B1F (dark brown bg)
**Typography**: Cooper Black (headings), Avant Garde (body)
**Visual traits**:
- Bulbous, rounded "bubble letter" display type with heavy outlines
- Psychedelic wavy stripes, sunburst patterns, and swirling groovy line art
- Warm earthy-saturated palette (orange/brown/gold) with occasional metallic accents
**Not this if**: The brand needs clean, minimal, or corporate-serious visuals.

For deeper technique detail (exact CSS/animation implementation), web-search for "70s groovy disco design CSS bubble typography" rather than guessing — this file gives direction, not a full spec.
