# Material Design

**When to use**: Android apps and cross-platform Google-ecosystem products wanting tactile, motion-driven UI with a clear elevation system.
**Palette example**: #6750A4 (primary purple, M3 baseline), #625B71 (secondary), #FFFBFE (surface)
**Typography**: Roboto (UI text), Google Sans (display/headlines)
**Visual traits**:
- Layered "paper" surfaces with elevation expressed via soft drop shadows (dp-based)
- Filled and tonal buttons with fully rounded corners (M3) or 4px radius (M2)
- Ripple feedback on touch, floating action buttons, bottom sheets
**Not this if**: Building for iOS-first audiences or a brand needing a distinct, non-Google visual identity.

For deeper technique detail (exact CSS/animation implementation), web-search for "Material Design 3 CSS design tokens" rather than guessing — this file gives direction, not a full spec.
